## 🛠️ Technology Stack

- **Frontend:** React.js (v19) + Vite
- **Styling:** Tailwind CSS (v4) with `@tailwindcss/vite`
- **Smooth Scrolling:** [Lenis](https://lenis.dev/) Smooth Scroll Engine (`lenis`)
- **Interactive Sliders:** [Swiper](https://swiperjs.com/) (`swiper/react`) for Works & Testimonials carousels
- **Icons:** Lucide React (`lucide-react`)
- **Routing & Code-Splitting:** React Router (`react-router-dom`) with `React.lazy` & `Suspense`

---

## 📄 Multipage Architecture

- **Home (`/`):** Full agency overview, live growth cockpit, regional AP & TG highlights, service index, Swiper project showcase, methodology, process, Swiper review slider, FAQ, and lead-generation form.
- **Services (`/services`):** Deep dive into 6 core agency capabilities (Web Development, SEO, Social Media, Google & Meta Ads, Branding, Video Editing) + AP & TG sector specializations.
- **Works (`/works`):** Interactive Swiper carousel + filterable deliverable catalog with case study modals.
- **About Us (`/about`):** Agency origin story, Guntur HQ + Hyderabad presence, 4-pillar approach, 5-step roadmap, and market comparison matrix.
- **Contact (`/contact`):** Lead inquiry form with service preselection, instant WhatsApp direct chat, phone support, and office address.
- **Privacy Policy (`/privacy-policy`) & Terms (`/terms`):** Professional legal compliance & 100% code ownership guarantee.
- **Custom 404 (`/*`):** Branded error page.

## 📈 SEO & Regional Optimization (AP & Telangana)

- **Regional Focus Areas:** Guntur, Hyderabad, Vijayawada, Visakhapatnam, Warangal, Tirupati, Rajahmundry.

## 💻 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/Suneel-rgb/Suneel-Media-Tech.git

# Navigate into the project
cd Suneel-Media-Tech

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
